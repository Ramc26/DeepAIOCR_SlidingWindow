Orchestration Pipeline (classifier.py)

Sequential state machine with retry & failure isolation

1. Assemble Window & Truncate MAX_PAGE_CHARS=12000
Injects prev_label + boundary null guards.
2. classifier.CallOpenRouter attempt: 1/3
POST /v1/chat/completions (OpenRouter or Cloudflare Workers AI compatibility layer)
3. Output Schema Validation {"label": "..."}
Enforces strict JSON + allow-list: Invoice | Purchase Order | Contract | Appendix | Other
4. State Carry-Forward to Page N+1 State → N+1
On failure: outputs label: null, status: "failed" and passes predicted_label: "UNKNOWN" to Page N+1.
Timeout: 45s Retries: MAX_RETRIES=2 Temp: 0.0
